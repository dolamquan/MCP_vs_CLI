
# CLI vs MCP Frontend

Frontend for the CLI vs MCP Token Analyzer. It includes the landing page, dashboard, workflow analysis, comparison history, and settings UI.

## Run locally

1. Install dependencies with `npm install`
2. Copy `.env.example` to `.env` if you need a custom backend URL
3. Start the app with `npm run dev`

By default the frontend expects the backend API at `http://localhost:5000/api`.

## Scripts

- `npm run dev` starts the Vite dev server
- `npm run build` creates a production bundle
- `npm run preview` serves the production build locally
